# اصلاح چندزبانه GeneratePress — نسخه ۳

- زبان واقعی صفحه (`fa-IR`، `ar-IQ`، `tg-TJ` یا `en-US`) در رویدادهای Analytics ثبت می‌شود.
- کلیک لینک داخلی دیگر با `preventDefault` و انتظار نامحدود برای callback متوقف نمی‌شود.
- ارسال آمار لینک‌ها با `beacon` انجام می‌شود و مرور عادی لینک ادامه پیدا می‌کند.
- فایل `footer.php` باید جایگزین فایل هم‌نام در قالب GeneratePress اصلاح‌شده شود.
- پس از نصب، کش وردپرس، سرور و CDN پاک شود.
